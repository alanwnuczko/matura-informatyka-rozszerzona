# matura-informatyka-rozszerzona

Rozwiązania arkuszy maturalnych z informatyki rozszerzonej: kod w Pythonie, kwerendy SQL, bazy Access i formuły Excel. To repozytorium jest źródłem danych dla [InfMatura](https://github.com/alanwnuczko/InfMatura) - wyszukiwarki arkuszy dostępnej pod [infmatura.dev](https://infmatura.dev).

## Uruchomienie lokalne

```
git clone https://github.com/alanwnuczko/matura-informatyka-rozszerzona.git
cd matura-informatyka-rozszerzona
```

Rozwiązania Python wymagają Pythona 3.x. Pliki Excel (`.xlsx`) i Access (`.accdb`) wymagają odpowiednio MS Excel i MS Access.
